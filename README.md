# Academic website

Static single-page site. Open index.html or serve with `python -m http.server 8000`. Upload all files to the root of your GitHub Pages repository. No build step.

- The portrait is at `assets/portrait.jpg`. Replace it to update your photo.
- Replace `files/cv.pdf` when updating the CV.
- Add licensed replication files to `files/` and link to them in Research. Do not redistribute restricted source datasets.
- Figure 1 is extracted from the provided manuscript. Dark recoloring changes pixel colors only; original included.
- Fonts are requested from Google Fonts; local system fallback applies when offline.
- Verify DOI links, current statuses, permission to list ongoing ESS projects, and CV before publishing.
- No analytics, cookies, theme toggle, or news feed.
